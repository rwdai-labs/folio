Triggers

              
Event hooks

            

            0
          

          

            Folio does not poll. Any external watcher — a script, a CI job, another
            server — posts a signed event here and Folio starts one maintenance run.
            Each hook has its own secret; unsigned, stale, or replayed requests are refused.
